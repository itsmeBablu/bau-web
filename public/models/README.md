# Courtyard Pavilion demonstration model

`courtyard-pavilion.glb` is an original parametric architectural study generated specifically for this website. It contains simple box-primitives for the site base, courtyard walls, roof, clerestory, entry screen, columns and pergola. It includes no externally sourced geometry, textures, logos or trademarks.

The model and its source are dedicated to the public domain under **CC0 1.0**. Attribution is appreciated but not required.
